# Security Policy 🛡️

## Supported Versions

We actively release security patches and updates for the following versions of **WebSocket Serverless**:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of **WebSocket Serverless** very seriously. If you discover a security vulnerability or potential threat, please report it responsibly:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Email your report directly to the maintainer: **Maximiliano Contartesi** via GitHub ([@mcontartesi](https://github.com/mcontartesi)).
3. Include detailed steps to reproduce the issue, proof-of-concept code, or HTTP request trace if applicable.

---

## Response Process

- **Acknowledgment**: You will receive an initial response within 24 to 48 hours acknowledging receipt of your report.
- **Investigation**: We will investigate and verify the reported vulnerability.
- **Fix & Disclosure**: A security patch will be prepared, tested, and deployed via a new patch release. We will coordinate public disclosure after the patch is published.
